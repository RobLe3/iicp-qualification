## Consolidated remaining decisions

1. Complete supported-scope and operational dispositions, including explicit unresolved evidence and controlled source prerequisites.
2. Select the exact minimal corrected sources and version/candidate identity; do not automatically adopt public main.
3. Bind all final artifacts, dependencies, build/package manifests, environments, harnesses and assignments.
4. Independently review corrected-defect regressions and the formal qualification required by current policy.
5. Obtain separate applicable execution and resource authority.
6. Freeze only after required regressions, qualification, certificates and supported-scope defect clearance pass.

The existing target compiler requires sixteen receipts with shard indices 0–15 per target; the ecosystem compiler joins four targets. Candidate-bound admission remains separate and adds no duplicate campaign credit. This is not an automatic schedule, a decision about additional admission executions, or a rule that every documentation/tooling edit outside an unchanged candidate reruns workloads. Scoped compatibility research under #1588 is not an existing exception.
