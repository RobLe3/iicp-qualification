# Offline rate-helper reference slice

Five literal helper fragments from exact public qualified SDK/Directory sources are retained with their original file hashes, line ranges and commits. Fixed synthetic vectors exercise boolean relay admission, registration-counter steps and a redirect-header clamp. These are different contracts—not an end-to-end rate-limit or retry guarantee.

## Verify and reproduce

Python 3.13 verifies the pinned bundle without running helpers:

```sh
python3.13 -B scripts/ifrb_rate_helpers.py verify
```

With a reviewed local Node 22+, Rust compiler and PHP installation, ordinary local helper validation can be run explicitly:

```sh
python3.13 -B scripts/ifrb_rate_helpers.py run --output /your/private/new-output-directory \
  --node /path/to/node --rustc /path/to/rustc --php /path/to/php
```

The output directory must not exist. Existing output is never cleaned or replaced. Generated wrappers, command output and observation records remain local; this command does not publish them. Timeouts apply per direct subprocess; output sizes are checked after exit. This is not a sandbox, process-tree deadline or streaming hard quota. Inspect retained partial outputs after any failure; there is no automatic retry.

The initial maintainer observation used CPython 3.13.18, Node 22.23.2, Rust 1.99.1 and PHP 8.5.12: 12 matched relay sequences per SDK, eight registration steps and eight PHP clamp values matched independently authored expectations. Independent review recomputed the 52 observations mathematically. These host/tool versions are not the original qualified runtime matrix.

## Exact scope

- Python/TypeScript/Rust: the selected relay admission methods run in synthetic holders with explicit small limits and source keys. Time is injected in integer milliseconds, converted to seconds for Python. Constructors, sockets, authentication and real relay bindings do not run.
- Rust Directory: only the pure registration-count/window step runs. The real handler, IP extraction, locking, threshold and HTTP response do not run.
- PHP Directory: only the literal clamp statement runs with a synthetic `config()` function. The real middleware, redirect and response do not run.
- Accepted case labels and 210 existing public coordinate references identify provenance; these new helper observations grant no additional qualification credit or evidence admission.

The selected historical cases do not establish the entire bounded-retry requirement. Relay routing remains experimental. Cache pruning above 4,096 entries, counter overflow, concurrency and clock anomalies are excluded; static source inspection finds different equality retention at the pruning cutoff, without establishing a current product defect. Boolean agreement over these vectors is not universal state or implementation equivalence.
