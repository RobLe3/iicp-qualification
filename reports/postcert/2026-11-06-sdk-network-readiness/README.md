## Authority and limits

The original root qualification ledgers, validators and certificates retain authority. All 768 assignment IDs already exist in the pinned [public analysis](../../analysis-v2/analysis.json); linking them here does not reinterpret old credit. Their mode/flavor labels are recorded contexts, not evidence that each mock or pure predicate exercised every real Directory configuration.

Protocol context is scoped. Its proxy-to-adapter retry table is not a universal SDK retry mandate. Certificate validation and production TLS/scheme requirements exceed the selected HTTPS-to-HTTP rejection tests. Conditional model-field guidance for registration is not a universal health schema for every non-model intent. The selected source health checks define a finite missing-field assertion.

Five source findings record common assertions and differences without claiming new runtime observations. One source-only difference is Python's exact 200 health gate versus TypeScript/Rust success-status ranges; the selected tests use 200. This is not a demonstrated product defect or a reason to invalidate accepted evidence.

[The source map](source-map.json) discloses the limitations for every case, including missing successful-DNS/TLS controls, unmeasured bounds and partial lifecycle coverage. Its source assertions are not performance results, independent interoperability, complete capability conformance, successor qualification or release readiness.
