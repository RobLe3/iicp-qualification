## Evidence layers supplied here

| Layer | Readable material | What it establishes | What it does not establish |
|---|---|---|---|
| Narrative | Six linked Markdown documents | Scope, findings, limits and next decisions | New qualification authority |
| Public derivatives | Status, receipts, certificates, coverage, events and assignment scope | Reported admitted identities and finite accounting | Full private run reproduction |
| Provenance | Source index and package manifest | Origin references and exact packaged bytes | Truth from a hash alone |
| Local verification | Supplied verifier and checked schemas | Integrity and internal consistency within its documented checks | Rerun of native workloads or private validator equivalence |
| Restricted originals | Available only through separately authorized maintainer access | Original attempt and execution details where retained | Complete history by default |

Never treat copied narratives or two reports derived from one receipt as
independent corroboration. Retain original timestamps, PASS/FAIL dispositions and
successor relationships. Failure causes remain unknown unless the original
observation and correction evidence establish them.

source registry, D01–D14 architecture crosswalk, V01–V13 reviewer crosswalk and
build scripts. The private review pinned 51 inputs/outputs and did not edit or

DMSC mappings remain **UNASSESSED** in the foundation projection. IICP functional
qualification is not proof of DMSC wire equivalence, independent interoperability,
reviewer endorsement or IETF acceptance. Any later appendix must link reviewed
claims to exact evidence and preserve these distinctions.

## Safe handling

Verify the package before reading it as evidence. Keep an original snapshot and
record any later correction as a versioned successor. Do not edit accepted source
records, move private archives into this tree or publish the maintainer locator
map. A digest mismatch is a stop-and-investigate result—not a reason to regenerate
expected hashes from whatever bytes happen to be present.

No cloud authentication, resource query, allocation, test rerun, deletion,
publication, deployment or release command is part of this handoff's verification.
