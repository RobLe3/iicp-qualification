# Contributing

Report inaccuracies using the public source and receipt identifiers, not private logs. Do not paste credentials, cloud identifiers, authorization records or workload payloads into issues or pull requests.

Generated report changes use the bounded publisher described in REPORTING.md. Other changes need review and focused local tests. Keep code, schema and policy changes separate from routine status updates. Preserve earlier failure records and state what was observed versus inferred.

The repository uses Apache-2.0. The private evidence archive is not part of this distribution. No contribution here changes the protocol specification or qualification acceptance rules.
